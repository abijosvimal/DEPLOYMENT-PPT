    📝 Prompt Engineering

    The 5-Part Formula

    • 🎭
      ROLE"You are a Python Flask developer..."
    • 📋
      CONTEXT"Building a college ERP with JSON data files..."
    • 🎯
      TASK"Create a student attendance tracking page..."
    • 📐
      FORMAT"Use HTML + plain CSS, no external libraries..."
    • ⚠️
      CONSTRAINTS"Keep it minimal and beginner-friendly..."
    Role + Context + Task + Format + Constraints = 🔥
    📝 Prompt Engineering

    Bad vs Good — Side by Side

    ❌ Too vague

  • "Create a form"
  • "Fix my code"
  • "Make it better"

    • ✅ Specific & clear

  • "Create HTML attendance form with checkboxes, date picker, submit. Dark theme."
  • "Flask /admin/students returns 404 on POST. Here's my code: [paste]. Fix it?"
  • "Add hover animations, gradient backgrounds, glass card effect."
    • 📝 Prompt Engineering

    3 Patterns That Always Work

    BUILDER: "Build [feature] for [project]. It should [requirements]. Use [tech]."
    FIXER: "Getting [error] when I [action]. Code: [paste]. What's wrong? Fix it."
    IMPROVER: "Current [thing]. Want it to [better how]. Keep [X] the same."

    What is GitHub?

    GitHub = Google Drive — but for CODE
    • ✅
      Stores code safely in the cloud
    • ✅
      Tracks every change ever made — full history
    • ✅
      Lets teams collaborate on the same project
    • ✅
      Shows your work to employers & the world
    • ✅
      Triggers automatic deployments (Vercel uses this)

    Used by: Microsoft · Google · NASA · Netflix · and now YOU

    📦 GitHub

    4 Commands. That's All.

    git init # Start tracking a project (run once)
    git add . # Stage all changed files
    git commit -m "message" # Save a snapshot with a label
    git push # Upload to GitHub
    These 4 commands handle 90% of daily git work.
    ⚠️ Critical Rule

    The Golden Rule

    NEVER push secret files to GitHub.

    ❌ Never commit

  • API keys (Gemini, OpenAI...)
  • Passwords
  • Database credentials
  • .env files

    • ✅ How to protect

  • .gitignore — git ignores listed files
  • .env.example — safe template only
  • GitHub SCANS every push for secrets
  • It BLOCKS the push to protect you
