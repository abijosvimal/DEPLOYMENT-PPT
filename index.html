    The 5-Part Formula

    • 🎭
      ROLE"You are a Python Flask developer..."
    • 📋
      CONTEXT"Building a college ERP with JSON files..."
    • 🎯
      TASK"Create an attendance tracking page..."
    • 📐
      FORMAT"Use HTML + CSS, no external libraries..."
    • ⚠️
      CONSTRAINTS"Keep it minimal, dark theme..."

    ❌ Vague

  • "Create a form"
  • "Fix my code"
  • "Make it look better"

    • ✅ Specific

  • "Create HTML attendance form with checkboxes per student, date picker, submit button. Dark theme."
  • "Flask /admin returns 404 on POST. Code: [paste]. Fix it."
    • 📋 Cheatsheet — Print This

    3 Patterns That Always Work

    🔨 BUILDER: "Build [feature] for [project]. It should [requirements]. Use [tech]. Do not use [restrictions]."
    🐛 FIXER: "Getting [error] when I [action]. Here is my code: [paste code]. What is wrong? Fix it."
    ✨ IMPROVER: "Here is my current [thing]. I want it to [better how]. Keep [what to preserve] the same."
    These 3 patterns cover 95% of all AI interactions you will ever need.
